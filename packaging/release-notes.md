One place for Pocketfader, Nova and YTM Beacon.

- **Desktop** (Linux, Windows, macOS): unpack `orbit-desktop-*.tar.gz`, then run `./install.sh` on Linux, or `python3 -m orbit` (`py -m orbit` on Windows). Needs Python 3.9 or newer.
- **Android** (5.0 and newer): install `orbit-android-*.apk`, then install Pocketfader and Nova from it. The first time, Android asks you to allow Orbit to install apps.

Check downloads against `SHA256SUMS`. This is a pre-release.
