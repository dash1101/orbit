**Orbit** by NovaLabs: one place for Pocketfader, Nova and YTM Beacon. Nothing needs installing first: each download runs on its own.

| System | Download | Then |
|---|---|---|
| **Linux** (x86-64) | `orbit-*-linux-x86_64.tar.gz` | unpack, run `./orbit` |
| **Windows** (10 and 11, 64-bit) | `orbit-*-windows-x64.zip` | unzip, run `orbit.exe` |
| **macOS, Apple chips** (M1 and newer) | `orbit-*-macos-apple-silicon.zip` | unzip, drag `Orbit.app` to Applications |
| **macOS, Intel** | `orbit-*-macos-intel.zip` | the same |
| **Android** 5.0 and newer | `orbit-*.apk` | install it, then install Pocketfader and Nova from it |

**First launch on Windows and macOS.** These programs aren't code-signed (that needs a paid certificate), so Windows may show "Windows protected your PC" (choose *More info*, then *Run anyway*) and macOS may say the app can't be opened (right-click `Orbit.app`, choose *Open*, then *Open*).

Orbit shows itself in an app window of Edge, Chrome or Brave when there is one, otherwise in your browser. Closing the window ends it.

Check downloads against `SHA256SUMS`. This is a pre-release.
